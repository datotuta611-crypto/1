# Задание: песочница Claude Code на этом VPS

## Цель

Установить Claude Code в Docker-контейнер так, чтобы:

- каждый запуск видел только один проект: `claude-box <папка проекта>`;
- вход был по подписке Claude, без API-ключа;
- контейнер работал от обычного пользователя, а не от root.

Всё делает скрипт `setup-claude-box.sh` из этой же папки. Не переписывай его и не собирай схему вручную.

## Шаги

1. **Проверь окружение:** `cat /etc/os-release`, `id`, `docker compose version`.
   Если нет Docker или compose v2, установи Docker Engine и `docker-compose-plugin` из официального репозитория Docker по инструкции для этой ОС: https://docs.docker.com/engine/install/. Через snap не ставь.

2. **Спроси пользователя**, если ещё не знаешь: имя и почту для git-коммитов (можно пропустить) и где лежат проекты.

3. **Запусти скрипт.**
   - Под root: `CB_USER=dev GIT_NAME="…" GIT_EMAIL="…" bash setup-claude-box.sh`
   - Под обычным пользователем с доступом к Docker: то же самое без `CB_USER`.

   Код выхода 0 и строки `[setup] ИТОГ` означают успех. Код 2 означает, что нет Docker. Код 1 — читай строку `[setup] ОШИБКА`, устрани причину и запусти скрипт снова: повторный запуск безопасен.

4. **Проверь каждый проект.** Под root:
   ```bash
   runuser -u dev -- /home/dev/.local/bin/claude-box /путь/к/проекту --version </dev/null
   ```
   Под обычным пользователем команда та же, только без `runuser -u dev --`. Должна вывестись версия Claude Code.

   Если вместо версии пришло `принадлежит другому пользователю` или `не найдена или к ней нет доступа`, **остановись и спроси пользователя**. Предложи перенести проект в `/home/dev/projects/` и/или выполнить `chown -R dev:dev` на эту папку, назвав точные пути. Делай это только после явного согласия.

5. **Вход по подписке выполняется только вместе с пользователем.**

   Лучше всего, если пользователь сам зайдёт по SSH и выполнит `sudo -iu dev` (под root: `su - dev`), затем `claude-box /путь/к/проекту auth login`. Он откроет ссылку в браузере и вставит код.

   Если зайти по SSH он не может, проведи вход через tmux (установи `tmux`, если его нет):
   ```bash
   runuser -u dev -- tmux new-session -d -s cblogin -x 400 -y 50 \
     "/home/dev/.local/bin/claude-box /путь/к/проекту auth login"
   runuser -u dev -- tmux set-option -t cblogin remain-on-exit on
   sleep 10
   runuser -u dev -- tmux capture-pane -p -J -t cblogin | grep -o 'https://claude.ai/oauth/authorize[^[:space:]]*'
   ```
   Отправь пользователю ссылку целиком и попроси прислать код, который он увидит после входа. Ссылка привязана к этому процессу: пока ждёшь код, не перезапускай сессию, иначе код не подойдёт. Получив код:
   ```bash
   runuser -u dev -- tmux send-keys -t cblogin -l 'КОД'
   runuser -u dev -- tmux send-keys -t cblogin Enter
   sleep 8; runuser -u dev -- tmux capture-pane -p -J -t cblogin | tail -5
   runuser -u dev -- tmux kill-session -t cblogin
   ```
   Не сохраняй код ни в файлах, ни в логах.

   Проверка входа:
   ```bash
   runuser -u dev -- /home/dev/.local/bin/claude-box /путь/к/проекту auth status </dev/null
   ```
   Должно быть `"loggedIn": true`.

6. **Отчитайся пользователю:** приведи строки `[setup] ИТОГ`, список проектов с результатом проверки и статус входа. Передай ему раздел «Как пользоваться».

## Запрещено

- Создавать, запрашивать или прописывать `ANTHROPIC_API_KEY` и любые другие ключи: ключ перекрывает подписку.
- Запускать контейнер от root и монтировать в него `/`, `/root`, домашнюю папку или папку со всеми проектами сразу.
- Без явного согласия пользователя переносить или удалять проекты, менять их владельца или права.
- Включать `--dangerously-skip-permissions` по умолчанию, вписывать его в скрипты или алиасы.
- Менять настройки Docker-демона, сети, файрвола, открывать порты.
- Править `setup-claude-box.sh` или файлы, которые он создаёт. Если скрипт падает по причине, которую нельзя устранить в системе, остановись и опиши ошибку пользователю.

## Как пользоваться (передай пользователю)

- Зайти на сервер: `ssh …`, затем `sudo -iu dev` (под root: `su - dev`).
- Открыть проект: `claude-box /путь/к/проекту` или `cd /путь/к/проекту && claude-box`.
- Продолжить прошлую сессию проекта: `claude-box /путь/к/проекту --continue`.
- Несколько проектов можно запускать одновременно в разных терминалах. Лимиты подписки у них общие.
- Работа без подтверждений: `claude-box /путь/к/проекту --dangerously-skip-permissions`. Только для доверенных проектов: в этом режиме агент может прочитать всё, что есть в контейнере, включая данные входа.
- Обновить Claude Code: `claude-box --update`.
- Выйти из аккаунта: `claude-box /путь/к/проекту auth logout`.
